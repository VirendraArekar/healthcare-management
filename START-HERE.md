# Start here

1. Read README.md for Docker Compose setup and generated demo credentials.
2. Read docs/PROJECT-STRUCTURE.md to study controller → service → repository → DAO boundaries and the frontend pages/components/store structure.
3. Read docs/FEATURE-MATRIX.md and docs/TEST-REPORT.md for implemented workflows and actual checks.
4. Read docs/BOOT-MIGRATION.md for the authorized Boot 4 / Spring 7 upgrade.
5. Review docs/SECURITY-REPORT.md and docs/DEPLOYMENT-VALIDATION.md before publishing or using real information.

The ZIP contains source, migrations, seeds, infrastructure, automation, tests and evidence. Dependencies and generated credentials are intentionally not bundled. Run scripts/init-local.sh to create your own .env, then follow the README.
